# ShopEase 🛍️

A clean and responsive e-commerce website built with **React and Vite**.

## Features

* Product listing
* Product search
* Category filtering
* Product details
* Add to cart
* Increase/decrease quantity
* Remove from cart
* Responsive modern UI

## Tech Stack

* React
* Vite
* React Router
* CSS

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal to view the website.
